# Sales Analysis Dashboard (Tableau Project)

## Project Overview

This project analyzes regional sales and profit performance using
Tableau.

## Tools Used

-   Tableau
-   CSV Dataset

## Dataset Description

The dataset contains: - Order_ID - Region - Category - Sales - Profit

## Suggested Dashboard Views

-   Region-wise Sales Comparison
-   Profit by Category
-   Sales vs Profit Trend

## How to Use

1.  Open Tableau.
2.  Connect to 'Tableau_Sales_Data.csv'.
3.  Create visualizations using Region, Category, Sales, and Profit.
4.  Build an interactive dashboard.
